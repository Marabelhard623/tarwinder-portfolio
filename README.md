## ❓ Frequently Asked Questions

**Q: Do I need to install anything?**  
A: No. This is a static website. You only need a modern web browser (like Chrome, Firefox, or Edge).

**Q: Can I edit the portfolio to show my own work?**  
A: Yes! If you know HTML and CSS, you can edit the files in the extracted folder. For more advanced customization, knowledge of React and TypeScript is helpful.

**Q: How do I deploy this to my own GitHub Pages?**  
A: Fork the repository on GitHub, enable GitHub Pages in the repository settings, and select the `gh-pages` branch as the source.

**Q: The page looks broken. What should I do?**  
A: Make sure you extracted all files from the ZIP. The `index.html` file must be in the same folder as the `assets` folder. Try refreshing the page.

**Q: Is there a way to preview the portfolio without downloading?**  
A: Yes, you can visit the live demo link (if available) on the repository's main page.

## 🧪 Running Locally (for developers)

If you are familiar with Node.js and want to run the development server:

1. Install Node.js from [nodejs.org](https://nodejs.org/).
2. Open a terminal (Command Prompt or PowerShell) in the extracted folder.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to start the development server.
5. Open the URL shown in the terminal (usually `http://localhost:5173`).
